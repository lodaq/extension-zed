Set up the Zed downloader

Video downloads use a separate user-level helper and your installed yt-dlp. No administrator companion or browser policy changes are needed.

  1. Install Python 3.10 or newer, yt-dlp, and optionally ffmpeg using your operating system’s package manager or their official installers. Make sure yt-dlp --version and ffmpeg -version work in a terminal.
  2. Find Extension Zed’s 32-letter ID on chrome://extensions or brave://extensions, with Developer mode enabled.
  3. From the Extension Zed source folder, run the command below for your system. Replace EXTENSION_ID with your ID. For Brave append --browser brave on macOS/Linux, or -Browser brave on Windows.

Linux / macOS

python3 downloader/install.py EXTENSION_ID

Windows PowerShell

.\downloader\install-windows.ps1 -ExtensionId EXTENSION_ID

Keep the source folder available until installation finishes. The installer copies the helper to your user profile and registers it for only your extension ID. It does not install yt-dlp or ffmpeg.

Return to Zed → Misc → Video downloader → Check again. Restart the browser if you changed PATH.

Files are saved to ~/Downloads/Zed. Without ffmpeg, only single-file videos and native audio formats are available. MP3 conversion and merging need ffmpeg.

Update asks yt-dlp to self-update. If your package manager installed it, update it through that package manager when self-update is unavailable.

Download only content you own or have permission to save.

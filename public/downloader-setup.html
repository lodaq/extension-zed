Set up the Zed downloader

Full video and audio downloads need a one-time local helper installation. Browser extensions cannot install native programs themselves. Once installed, Zed connects automatically; no extension ID or browser configuration is needed.

  1. Install Python 3.10 or newer, yt-dlp, and optionally ffmpeg using your operating system’s package manager or their official installers. Make sure yt-dlp --version and ffmpeg -version work in a terminal.
  2. Install Extension Zed in Chrome or Brave before running the helper installer.
  3. From the Extension Zed source folder, run the command below for your system. The installer detects Zed in your Chrome and Brave profiles automatically.

Linux / macOS

python3 downloader/install.py

Windows PowerShell

.\downloader\install-windows.ps1

Keep the source folder available until installation finishes. The installer copies the helper to your user profile and registers it for the detected Zed extension IDs only. It does not install Python, yt-dlp or ffmpeg.

Return to Zed → Misc → Video downloader. It connects automatically when opened. If the view was already open, choose Check again. Restart the browser if you changed PATH.

Files are saved to ~/Downloads/Zed. Without ffmpeg, only single-file videos and native audio formats are available. MP3 conversion and merging need ffmpeg.

Update asks yt-dlp to self-update. If your package manager installed it, update it through that package manager when self-update is unavailable.

Download only content you own or have permission to save.

Extension Zed — Design reference

The visual source of truth for the redesigned popup: the Zed Dark design system and every screen and state, rendered at the real popup size (640 × 600 px). Written to be handed to a coding agent together with extension-zed-design-spec.md.

How to use: tokens live in <style id="zed-tokens">; component CSS in <style id="zed-components"> (classes prefixed zed-); each screen is a <figure data-screen="…">. Sample data (links, extensions, current values) is placeholder. This file is a reference, not production code: re-implement in the extension’s own stack.

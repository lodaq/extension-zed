Video downloader setup

Copy the command for your OS, paste it into a terminal as your normal user, and press Enter. It installs missing Python, yt-dlp, and FFmpeg packages, then registers the Zed helper. Your package manager may prompt for approval.

Linux or macOS

Supported package managers are apt on Debian or Ubuntu, pacman on Arch Linux, and Homebrew on macOS.

Windows

Use Windows PowerShell with WinGet (App Installer). Restart Chrome or Brave after installing packages so it picks up your updated PATH.

Return to Zed → Misc → Video downloader and click Check again if shown.
